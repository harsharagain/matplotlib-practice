# Matplotlib Practice 📊

A collection of my **Matplotlib practice programs and examples** while learning data visualization with Python.

This repository contains small, focused examples covering the basics of Matplotlib and gradually moving toward more advanced plotting concepts.

## 📚 Topics Covered

| #  | Topic             | Description                            |
| -- | ----------------- | -------------------------------------- |
| 01 | `getting_started` | Basic Matplotlib setup and plots       |
| 02 | `markers`         | Markers and marker customization       |
| 03 | `line`            | Creating and customizing line plots    |
| 04 | `labels`          | Titles, labels, and axis customization |
| 05 | `grid`            | Adding and customizing grids           |
| 06 | `subplots`        | Creating multiple plots with subplots  |
| 07 | `scatter`         | Creating and customizing scatter plots |
